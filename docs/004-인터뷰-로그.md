## 라운드 1 (2026-08-20): RAGFlow 접속 확인
### 사용자가 제공한 것
- RAGFlow 접속: https://ragflow.ax-demo.com (관리자 계정 / 비밀번호는 대화 외 별도 보관)
- 서버는 같은 서버가 아님 → **HTTP API로만 호출**

### 확인된 사실
- `https://ragflow.ax-demo.com/api/v1/datasets`, `/chats`, `/agents` 응답 확인 (401 = 엔드포인트 존재, 인증 필요)
- 로그인 API(`/api/v1/user/login`)는 이 서버에 없음 → **API 키 방식** 사용
- RAGFlow REST API는 `Authorization: Bearer <API_KEY>` 헤더 인증
- API 키는 RAGFlow 웹 UI에서 발급 (아바타 → API → 새 키) — 공식 절차 Serper 검색으로 확인 완료 (ragflow.io/docs/acquire_ragflow_api_key)

### 결정
- 앱 ↔ RAGFlow는 REST API로 연동 (구현: RAGFlow 클라이언트 모듈)
- API 키는 서버 환경변수 `RAGFLOW_API_KEY`로 관리 (코드/문서에 평문 저장 금지)
