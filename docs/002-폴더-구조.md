# 002. 폴더 구조 (v0.2 — 구현 반영)

## 저장소 루트
- `docs/` — 설계 문서, `docs/features/*.md` — 기능별 구현 지시서
- `app/` — 웹앱 코드 (스캐폴드 완성 + 테스트, 동작 검증 완료)
- `docker-compose.yml` — Docker 배포 예시 (루트)

## app/** (Next.js 16 App Router + TS + Drizzle/SQLite)
```
app/
├── next.config.ts          # serverExternalPackages: better-sqlite3
├── drizzle.config.ts       # drizzle-kit 설정 (SQLite)
├── .env.example          # 모든 환경변수 예시 (복사 후 실제 값 입력)
├── data/                # SQLite DB (git 제외, Docker 볼륨: /app/data)
├── Dockerfile / .dockerignore   # Next standalone 이미지 (Node 22)
├── drizzle/                   # db:generate 마이그레이션 SQL (vitest setup에서 적용)
└── src/
    ├── tests/                # Vitest: auth/engine/대화/문서/SSE 통합 테스트 (24건)
    ├── app/
    │   ├── page.tsx            # 로그인
    │   ├── register/page.tsx    # 가입 (이메일 도메인 체크 + 부서 선택)
    │   ├── chat/page.tsx       # 메인 채팅 UI (SSE 스트리밍 수신)
    │   ├── documents/page.tsx   # 자료 업로드 + 파싱 상태 목록
    │   ├── admin/page.tsx      # 관리자: 가입 승인
    │   └── api/
    │       ├── auth/{register,login,logout,me}/route.ts
    │       ├── departments/route.ts
    │       ├── conversations/route.ts, conversations/[id]/route.ts
    │       ├── documents/route.ts     # 업로드 → RAGFlow 데이터셋
    │       ├── admin/users/route.ts  # 승인/거절 (admin 전용)
    │       └── chat/stream/route.ts # ★ SSE 스트리밍 (RAG 검색 + 페르소나 에이전트)
    └── lib/
        ├── config.ts           # 환경변수 중앙화 (SESSION_TTL_MS/RAG 임계값 포함)
        ├── db/{index,schema,seed}.ts
        ├── auth/{password,session,http,ratelimit}.ts  # 레이트리밋 포함
        ├── ragflow/{client,status}.ts  # RAGFlow REST 클라이언트 + 파싱 상태 매핑
        └── agent/{llm,personas,engine}.ts  # pi-ai 모델 + 부서 페르소나 + 실행
```
> 화면은 최소한의 동작형 데모. UI 고도화는 바이브 코딩 단계.

## 환경변수 (app/.env.example)
| 변수 | 용도 |
|---|---|
| `RAGFLOW_BASE_URL` / `RAGFLOW_API_KEY` | RAGFlow 외부 서버 |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | LiteLLM 게이트웨이 + DeepSeek 모델 |
| `ALLOWED_EMAIL_DOMAINS` | 가입 허용 도메인 (shinhan.com, shinhanlife.co.kr) |
| `SESSION_COOKIE_NAME` / `COOKIE_SECURE` / `SESSION_TTL_MS` | 세션 쿠키 / 만료(기본 7일) |
| `DATA_DIR` / `DATABASE_URL` | SQLite 파일 경로 |
| `RAG_TOP_K` / `RAG_SIMILARITY_THRESHOLD` | 검색 파라미터 |
