# 005. PI 에이전트 풀마운트 계획

> 상태: [진행 중] | 기준 태그: pi v0.84.2 | 날짜: 2026-08-24
> 목표: pi 4개 패키지 소스를 프로젝트에 직접 넣고(vendor), 이 앱이 **실제 PI 에이전트(pi-agent-core `Agent`)** 를 호출하며, PI 에이전트가 **보험금기획팀/계리팀 서브에이전트**를 호출해 답변을 생성하도록 재구성.

## 1. 확정 사항 (조사 완료)
- pi 저장소: `github.com/earendil-works/pi` **v0.84.2 태그 고정** (npm 설치 버전과 일치)
- 마운트할 패키지 4개: `pi-telemetry`, `pi-ai`, `pi-agent-core`, `pi-coding-agent`
- 구조: dept-agent(이 앱) → **PI 에이전트(pi-agent-core `Agent`)** → 서브에이전트(보험금심사기획팀/계리팀)
- pi-agent-core에는 서브에이전트 스폰 기능이 **없음** → 앱에서 `AgentTool`로 구현 (부서 페르소나를 가진 자식 `Agent` 실행 → 결과 반환)

## 4. 핵심 설계 (engine.ts 재작성)
- **PI 에이전트**: pi-agent-core `Agent` — systemPrompt(총괄), tools(부서 서브에이전트 호출), `models.streamSimple` 스트림 함수(LiteLLM)
- **서브에이전트**: 각 부서 페르소나(`personas.ts`)를 systemPrompt로 가진 자식 `Agent` — RAG 컨텍스트 주입, 질의를 받아 답변 생성
- **연결**: PI 에이전트의 `AgentTool.execute` 내부에서 자식 `Agent.prompt()` 호출(await) → 결과 반환 → PI가 종합
- **스트리밍**: `Agent.subscribe()`의 `message_update`(text_delta)를 SSE로 전달
