# f008. 드라이런 에이전트 평가 · 후보 연관 LLM 판단 · 지식 그래프 LLM 관계 · 에피소드 명확화

## 증상 → 목표
1. [후보 큐] "모든 후보에 연관/유사 지식 감지" → **LLM이 기존 지식을 검색·판단해 진짜 유사 항목만 선택**, 비교 시 기존 내용 병기
2. [드라이런] 휴리스틱 점수 대신 **실제 부서장 에이전트에 업무별 질문을 생성·질문하고 LLM-as-judge로 평가**
   (지식 공백/헛점, 과거 종료 이벤트를 현재로 오인하는 시점 오류 등 검증), 업무별 질문 자동 생성 + 선택→평가
3. [에피소드] 의도 모호 → 배치(대화→지식) 중간 단위임을 명확화 + 결론 일괄 지식 저장 + 파생 후보 상태 표기
4. [대시보드→채팅] "부서가 필요합니다" 경고 → 중복 자동전송 제거(수정 완료)
5. [지식 그래프] 연결을 사람이 안 만듦 → **LLM이 데이터 간 관계를 판단·저장** 후 그래프 표시 + 관계 구성 버튼

## 검증 로직 (웹검색 기반, LLM-as-judge)
- 관련성(answer relevance), 근거 충실성(groundedness/faithfulness — 출처 없는 주장/할루시네이션),
  지식 공백(knowledge gap), 시점 정합성(temporal grounding — 과거 회의록 종료 이벤트를 현재로 오인), 완결성
- 각 차원 0~100 + 근거, 종합 verdict(양호/보완필요/위험), latency 측정
- LLM 호출은 테스트에서 주입(call/ask/judge 파라미터) → 결정적·빠른 검증
