## 조사 결과 (근거)
- 대시보드(`src/app/(app)/dashboard/page.tsx`)는 `src/lib/dashboard/dashboardData.ts` 시드/목업 데이터 기반. KPI 카드(KpiCards), 월별 추이(TrendChart), 심사처리큐·지연관리(QueueCard + 다가오는 마감), 업무진도 모니터링(MonitorCard), 부서장 의견(DirectorNote) 존재.
- 검토큐 GET은 최근 휴리스틱 전환(이전 커밋 bcbe70e)으로 목록은 즉시 로드되나, 휴리스틱이 "단어 유사"만 봐서 모든 건을 유사로 표시. LLM 재판정(?related=1)은 정밀하지만 목록 기본값이 아님.
- 메모리 사용횟수: `store.ts`의 `bumpHitCount`가 존재하나 **어디에서도 호출되지 않음** → hitCount가 0인 채. RAG 검색·답변 반영 경로에 배선 필요.
- DB 테이블에 실보험금(월별 지급·사유별) 데이터 없음. 대시보드는 목업 데이터.
