# 008 — UI/UX 2.0 (AGENT-2026-08-24)

## 목표
10개 요구사항을 TDD로 구현하고 푸시한다.

| # | 요구 | 구현 |
|---|------|------|
| 1 | 사이드바 자동 숨김 | 반응형: 좁은 화면 자동 접힘 + 토글 버튼 (넓은 화면에도 토글 제공) |
| 2 | 사이드바 이전 대화 삭제 | DELETE API(이미 존재) + 행 hover X 버튼, 삭제 후 목록 갱신 |
| 3 | admin 부서 선택 팝업 제거 → 사이드바 선택 | showDeptPicker 오버레이 삭제; 사이드바 세그먼트를 admin 전용으로 유지 (일반 유저 숨김). 새 대화 시 admin은 activeDepartmentId 사용 |
| 4 | 자료관리 오류 수정 + 사용자별 | POST 핸들러 누락 복원; GET/DELETE를 userId 필터로 변경; RAGFlow 강제 제거(오류 원인) |
| 5 | 입력/출력 크기 변동 + 화면 꽉 참 | 메시지 영역 flex-1 + max-w-4xl→5xl 확대, 입력/출력 동적 높이 |
| 6 | "/" 슬래시 커맨드 | /api/skills (서버, getPersonaSkills) 목록 + 채팅 입력 "/" 시 팔레트 표시(스킬·기능 + 설명) |
| 7 | 입력창 줄바꿈 자동 확장 + 최대 높이 스크롤 | textarea scrollHeight 자동 확장, max-h 초과 시 스크롤 |
| 8 | 채팅 파일 드래그/선택 업로드 (사용자별) | 입력 영역 drop/input → POST /api/documents (userId 소유) |
| 9 | RAG 데이터셋 부서별 추후 | 이번 범위: 개인 자료 관리 (userId 소유, RAGFlow 미연결 상태로 오류 없음) |
| 10 | thinking/tool 진행상황 표시 + 완료 접힘/확장 | engine에 onEvent(진행) 콜백 → SSE events(run/status/tool) → 채팅 진행 패널(접힘/펼침) |

## 파일
- schema.ts: documents에 size/mimeType/content? 추가 옵션, departmentId nullable 유지
- api/documents/route.ts: POST 복원(user별 저장), GET userId 필터
- api/documents/[id]/route.ts: 신규 DELETE (user 소유)
- api/skills/route.ts: 신규 — 부서 스킬 목록
- api/chat/stream/route.ts: 엔진 진행 이벤트 → SSE(run_start/status/run_end/tool_start/tool_end) 전달
- lib/agent/engine.ts: onEvent 옵션 추가, Agent.subscribe 이벤트 포워딩
- chat/page.tsx: 사이드바 토글/삭제/부서 세그먼트, 입력 auto-resize, 슬래시 팔레트, 드래그 업로드, 진행 패널, 폭 확대
- documents/page.tsx: 나의 자료 UX + 삭제 버튼 + 오류 표시

## 검증
- tsc --noEmit
- vitest run (기존 36 + 신규: documents POST user별, DELETE, skills API, chat-stream 진행 이벤트)
- 실서비스 curl: 문서 업로드/목록/삭제, SSE 이벤트 확인
