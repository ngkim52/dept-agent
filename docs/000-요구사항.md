# 000. 요구사항 (v0.1 초안)

## 1. 배경 / 목적
- 업무 관련 질문·자료 검증·조언·아이디어 제공을 위한 **부서장 페르소나 에이전트** 서비스.
- 사용자는 웹에 로그인 → 업무 질문 or 작성 자료 업로드 → 부서 담당 "부서장" 에이전트가 판단·답변.

## 2. 사용자 역할
- **사용자(직원)**: 로그인, 질문, 자료 업로드, 답변 확인.
- **관리자**: 사용자/부서 관리, 페르소나 설정, 모델·RAG 설정. *(범위 확인 필요)*

## 2-1. 적용 범위 (확정 2026-08-20)
- **1차 대상**: 보험금심사기획팀
- **2차 대상**: 계리팀 (설계/개발 완료 후 추가)
- 권한: **부서 내 공유** (같은 부서원끼리 문서 공유, 타 부서 접근 불가)

## 3. 주요 기능 (후보)
| 기능 | 설명 | 문서 |
|---|---|---|
| 인증/세션 | 로그인, 세션 유지, 권한 | features/f001 |
| 문서 업로드·RAG | 자료 업로드 → RAGFlow 인덱싱 → 검색 | features/f002 |
| 질문·응답 | 대화 화면, 엔진 연동, 스트리밍 | features/f003 |
| 부서장 페르소나 | 부서별 sub-agent 시스템 프롬프트/판단 로직 | features/f004 |
| 관리/설정 | 부서, 사용자, 모델, 페르소나 설정 | features/f005 |

## 4. 비기능
- Web 동시 접속 (수 명 ~ 수십 명 규모 가정)
- Docker 이미지로 배포
- RAGFlow는 별도 서비스로 운영 (본 앱과 분리)
