# f003. 질문·응답 (대화 ↔ 에이전트 엔진, SSE) (확정 2026-08-20)

## 요청 (클라이언트 → 서버)
- `POST /api/chat/messages` {conversationId?, content}
- 또는 대화 기본 스트림: `GET/POST /api/chat/{conversationId}/stream` (SSE)

## 서버 처리 (SSE 응답)
```
1. 세션 검증 → 사용자 부서 확인
2. (optional) 기존 대화 이력 로드
3. RAGFlow retrieval(product: 부서 데이터셋) → top-k 청크
   - 검색 결과 없거나 부서 문서 없으면 → "RAG 없이 일반 답변" 허용
4. pi-agent-core Agent 생성 (부서 페르소나 systemPrompt, 추가 컨텍스트: 근거 청크)
5. subscribe() 이벤트 → SSE 프레임 변환:
   event: text    data: {"delta":"..."}
   event: citations data: {"items":[{doc, chunk, sim}]}
   event: done    data: {"messageId": "..."}
   event: error   data: {"message":"..."}
6. 스트림 종료 후 대화/메시지 DB 저장
```

## SSE 포맷 (정의)
```json
: keep-alive로 연결 유지
{"event":"text_delta","data":"..."}
{"event":"citations","data":"[{...}]"}
{"event":"done","data":null}
```

## 클라이언트 (화면)
- 채팅창: 대화 목록 / 질문 입력 / 스트리밍 렌더 / 근거(참조문서) 카드
- 부서는 가입 선택 부서로 고정 (1차), 전환/멀티는 2차에서 논의
- 에러: 재시도 버튼

## 주의
- Agent 인스턴스는 요청당 생성(짧은 대화) → 장기 세션(RLM) 성격은 2차에서 재검토
- 대화 감정 중복·재시도·타임아웃 처리 필요
