# f006. 지식 하네스 관리 · 수정/삭제 · 스킬 자동 생성

> 상태: **구현·검증 완료 (2026-09-15)** — 37 테스트 파일 / 202 테스트 통과 기준

## 개요
부서 페르소나에 주입되는 지식 하네스(프롬프트·스킬·메모리)를 관리자가 **보고·수정·삭제**하고,
원하는 스킬을 물어보면 참조 데이터 + 웹검색 보강으로 **스킬을 자동 생성**해 저장할 수 있다.

## 1. 하네스 관리 — 수정·삭제 (프롬프트/prompt · 스킬/skill · 메모리/memory)
- 화면: `app/src/app/(app)/admin/HarnessPanel.tsx` (하네스 관리 → 「스킬 편집」 탭, 타입 선택)
- **조회**: base(코드 내장, 읽기 전용) + learned(DB) 병합 인벤토리 — `src/lib/harness/inventory.ts` `listEffective`
- **수정**: `PATCH /api/admin/harness/:id?type=…` → `updatePrompt/updateSkill/updateMemory` (+ 버전 `update` 기록, 이력·복원 지원)
- **기능 토글(소프트)**: `DELETE /api/admin/harness/:id?type=…&active=false|true` → `setActive`
- **하드 삭제**: `DELETE /api/admin/harness/:id?type=…&hard=1` → `deleteEntry`
  - 기본(src/base) 항목은 코드 내장이라 삭제 불가(읽기 전용 표시), DB(learned) 항목만 삭제 가능
  - 삭제 전 `window.confirm`, 버전에 `delete` 액션으로 감사 기록 — 자동 삭제 금지 원칙은 유지(수동만 허용)
- 버전 기록·롤백: `src/lib/harness/store.ts` (`recordVersion` / `restoreVersion` / `listVersions`)

## 2. 스킬 자동 생성 (skill-maker)
사용자가「만들고 싶은 스킬의 목적」을 입력하면:
1. **컨텍스트 수집**: 기존 스킬(getPersonaSkills) · 메모리(knowledge_memories) ·
   최근 부서 대화(messages) · 부서 문서(documents)
2. **웹검색 보강**: 내부 데이터가 부족하거나「웹검색 보강 사용」이면 Serper/Tavily로 보강
3. **LLM 생성**: response 모델로 `{name, description, content(SKILL.md 본문)}` 초안 생성
4. **관련 스킬 탐색**: 주제와 매칭되는 기존 스킬 표시 (단, 장착 대상은 아래 스킬 생성기 스킬)
5. **사용자 확인 후 저장**: 수동 편집 → `POST /api/admin/harness?type=skill` 로 반영

- 백엔드: `src/lib/harness/skillgen.ts` (`generateSkillDraft` / `findRelatedSkills` / `parseSkillDraft`)
- API: `POST /api/admin/skills/generate?personaKey=…` `{topic, useWeb}`
- UI: `src/components/SkillAutoCreate.tsx` (스킬 탭 위저드)

### 「스킬을 생성해주는 스킬」 장착 (스킬 생성기)
자동 생성은 기능 차원의 것이며, **스킬 생성 방법론 자체를 스킬로 장착**한다.
- `src/skills/<claims-planning|actuarial>/스킬생성기/SKILL.md`
- 설명: 사용자가 새 스킬 생성을 요청할 때 목적·범위 확인 → 데이터 수집 → (부족 시) 웹검색 →
  SKILL.md 구조(요구시점/판단기준/데이터사용/출력)로 설계 — 이 스킬이 부서 페르소나 스킬 목록에 **장착**됨
- 매 생성마다 관련 스킬을 재탐색·장착하는 것이 아니라, **스킬을 만드는 스킬(생성기)** 한 벌을 에이전트에 장착하여 그 절차를 따른다.

## 보안
- 모든 하네스/스킬 생성 API는 관리자(requireAdmin) 전용
- 저장(오버라이트) 항목만 변경 가능, websearch는 서버 키(SERPER/TAVILY)로만 수행
