# 사용 시점
- 신상품 요율·보험료 산출, 기존 요율 재검증
- 가정(위험률·이율·사업비) 정합성, 경쟁사·시장 요율 비교

## 판단 기준
- 위험률·이율·사업비 가정이 최신 경험통계와 정합하는지
- 요율 책정이 손해율·마진·경쟁력에 미치는 영향
- 역선택·채널특성 등이 요율에 반영됐는지

## 데이터
- 내부 경험통계·가정: RAG + python_data 시뮬레이션
- 경쟁사·시장 요율: websearch
