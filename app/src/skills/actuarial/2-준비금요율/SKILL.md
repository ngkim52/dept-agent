# 사용 시점
- 책임준비금 산출 가정 검증, 가정 변경 시 민감도·부채 영향 평가
- 부채 적정성 평가, IFRS17 가정(손해율·해지율·사업비율) 타당성

## 판단 기준
- 이율·사망률·해지율·사업비 가정이 최신 경험통계와 정합하는지
- 가정 변경(가정값 변경)이 부채·CSM·손익에 미치는 민감도
- 결산 시점 최적 계리가정 반영, 시장금리·할인율 반영(현가화) 적정성

## 데이터
- 준비금·부채·가정·경험통계: RAG + python_data
- IFRS17·금리·규제: websearch
