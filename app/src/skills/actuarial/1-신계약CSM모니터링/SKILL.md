# 사용 시점
- 신계약CSM 실적·추이·계획 대비 평가, 물량·마진율 분해 원인 분석
- 신상품 모니터링(물량 유입, 마진율 정합, 기존 물량 shift), 이상 마진율(손실계약) 유의성, 부장→임원 escalate 판단
- 할인율 영향, VNB vs 신계약CSM 일관성, 동종업계 신계약CSM 규모/배수 비교

# 핵심 산식 (공식)
신계약CSM = 신계약물량(CMIP) × 신계약마진율(%)

## 모니터링 기준
- **실적 수준**: 신계약CSM 규모를 전월 대비·계획 대비로 평가.
- **주요 요인 분해**: 물량(CMIP) 요인 vs 마진율(%) 요인으로 분해 — CSM 변동이 물량 때문인지 마진율 때문인지.
- **마진율 변동 요인**: CSM 산출 시 적용한 할인율 수준 변동 가능성(점검), 계약속성(연령/성별/보험료수준/납입기간/보험기간) 유입 영향.
- **계약 속성 매핑**: '상품명'과 '상품군' 매핑 필요 — 상품군/상품별로 물량·마진율·CSM을 교차 분석.
- **이상 마진율(손실계약)**: 다수 손실계약 유입 시 수준이 유의미한지. % · CSM 규모('-' 영향) · 계획 대비를 기준으로 판단하고, 팀장→임원 escalate 필요 여부·영업채널 이상징후 여부를 함께 점검.

# 신상품 모니터링
- 신상품 판매 시 예상했던 물량만큼 유입? 기존 물량을 훼손하며 신상품 늘었는지? 기존 상품 감소가 예상치인지, 신상품으로의 물량 shift 과도했는지.
- 신상품 마진율이 개발 시 보고된 마진율과 유사한지. 다르다면 계약속성(성별/연령/보험료수준)별 마진율 유입 특성.

# 시계열·일관성·업계
- 신계약CSM 규모를 연간 월별/분기별 시계열로 보아 계획과 유사한 수준인지, 어떤 특징 있는지.
- VNB(신계약가치) 분석 결과와 신계약CSM 분석 결과가 일관된 메시지인지, 차이 있으면 어느 부분인지.
- 동종업계 신계약CSM 규모·배수를 공시·업계 자료로 비교(websearch 활용).

# 데이터 사용
- 내부: 월별·채널별·상품별 계획/실적 물량·마진율·신계약CSM, 결산 결과, 할인율, 계약속성별(가입금액·보험료·성별·연령·납입기간·보험기간·손실계약규모) 데이터 → RAG(신계약CSM 데이터셋) + python_data 집계
- 외부: 업계 신계약CSM·배수·VNB 공시, IFRS17·할인율·시장금리 동향 → websearch(URL 출처)
- 회의체 문서: 상품전략위원회·상품라운드테이블 회의록 → RAG(업로드된 문서)
