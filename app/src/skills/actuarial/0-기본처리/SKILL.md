## 사용 시점
- 계리 5대 업무 외 일반 질문(용어, 사내 제도, 회계 기본 개념 등)
- 어느 영역에 해당하는지 애매한 질문

## 처리 순서
1. 질문 성격 파악(의사결정/정보·보고/절차/데이터/이슈/개선)
2. 관련 영역 탐색: ①신계약CSM ②준비금 ③요율 ④건전성 ⑤경험통계 중 가까운 것 → 해당 스킬 절차 적용
3. 계리와 무관한 일반 질문은 부서장 관점으로 간결 안내, 외부 자료 필요 시 websearch
4. 근거 확인: 내부는 RAG, 외부(공시·규제·시장금리)는 websearch, 집계는 python_data

## 출력
[요약] → [관련 영역 판단] → [근거/시사점] → [권고 의견] → [추가 확인사항]
