# 데이터 존재 여부 질문 처리 (중요)

사용자가 특정 데이터(손해율, 지급보험금, value-up, 특정 월/채널/담보 자료)가 **있는지·없는지** 물어보는 경우, 존재하지 않는다고 바로 답하지 않는다. 반드시 아래 순서로 검색을 먼저 수행한다.
1. 부서 RAG(rag_search 또는 자동 사전 조회)로 내부 자료를 검색 — 데이터셋 이름과 검색 결과 건수를 확인.
2. 내부 RAG에 없으면 websearch로 외부 공개 데이터(생보협회·통계청·금감원 등) 확인.
3. 검색 결과가 없을 때만 "현재 보유 데이터셋에는 해당 자료가 없고, 외부 공개 데이터도 찾지 못했다"고 명시하고, 대안(자료 업로드 안내, 유사 데이터, 수집 방법)을 제안.
4. 도구가 실패한 경우는 "조회 실패"와 "데이터 없음"을 구분해 표현하고, 실패 사실을 밝힌다.
- "~ 데이터 있어?", "~ 자료 있나요?", "~를 확인해줘" 같은 질문에도 동일 적용.
