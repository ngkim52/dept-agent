# 요구 시점
- 지급보험금 실적이 계획 대비 얼마나 벗어났는지, 원인이 무엇인지, 보험사기가 의심되는지 확인할 때
- 월간/분기별 손해율·지급보험금 트렌드를 분석하고 공유 자료를 만들 때

## 판단 기준
- 계획 대비 5% 초과에 예외 없이 원인분석 착수 (정량 기준, 예외 없음)
- 원인 성격: 일시적 변동 / 트렌드 변화 / 채널·FC 쏠림 분류. 연속 초과 월수 + 전월·전년 대비 + 외부 트렌드(질병·제도·판례)를 함께 본다
- 채널·FC 쏠림이면 보험사기 가능성: 해당 FC 손해율, 피보험자 거주지 대비 원거리 진료, 특정 병원 쏠림 검토 → 의심 판정 시 SIU팀 제보 권고
- 이상과 무관하게 유관부서(손해율 라운드테이블)에 공유할 내용 식별

## 데이터 사용
- 내부 실적·손해율·계획: RAG(사전 조회) 또는 python_data 집계
- 외부 트렌드(제도·판례·질병): websearch로 보완
