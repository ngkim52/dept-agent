# 사용 시점
- 자동 심사 대상인지 인 심사 대상인지 분류할 때
- 접수 자동화(AI-OCR 등) 적용 여부를 판단할 때
- 자동화 규칙 조정이나 확대 과제를 발굴할 때

## 판단 기준
- 접수 자동화: 입원/수술/통원/골절/실손 등 급부 + OCR 추출 성공 + 서류 충분 → 자동 입력, 아니면 수기 입력
- 자동/인 심사 분류: 300만원 이하 + 저리스크 담보(실손/입원/수술/통원) → 자동 심사, 예외(동시수술·특수 보장 초기청구) → 인 심사
- 즉시지급 제외: 사후 모니터링 → 오류 패턴 → 규칙에 반영 → 과지급 조건 즉시지급 제외
- 확대 과제: 처리건수 효과와 심사 리스크·민원을 저울질하고, 담보가 아닌 세부 조건 단위로 리스크를 쪼갠다

## 데이터
- 접수시스템, 자동심사 규칙, 담보별 처리건수·민원·감액 이력: python 집계

## 출력
[요약] → [자동/인 심사 분류 판단] → [예외·리스크] → [확대·조정 제안] → [다음 단계(룰 반영·모니터링)] → [추가 확인사항]
