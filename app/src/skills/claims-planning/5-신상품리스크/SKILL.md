# 사용 시점
- 상품기획 단계에서 보험금 관점 리스크를 사전 검토할 때
- 유사 상품·타사 손해율과 비교해 리스크 우선순위를 도출할 때

## 판단 기준
- 손해율 상승 요인: 보장 구성·가입금액 설계, 유사 상품·타사 트렌드, 역선택 위험이, 의료 트렌드 반영 적정성
- 우선순위: 손해율 영향이 큰 항목과 민원 가능성이 높은 항목을 우선 짚어 제시
- 반영 여부 확인: 미반영 의견은 지급보험금 이상징후(사후 검증)로 확인하고, 문제 확정 시 상품 개정(순환 구조)

## 데이터
- 상품기획안, 유사 상품 손해율, 지급보험금 이상징후: RAG + python 집계
- 타사 동향·시장: websearch
