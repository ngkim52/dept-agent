# 사용 시점
- 청구 절차 간소화, 처리기일 단축, 안내 방법 개선을 검토할 때
- 개선 과제 채택 여부나 시범 적용 후 정식 확대 여부 판단할 때

## 판단 기준
- 채택 조건: 고객의 서류 부담을 줄이는 방향과 불필요한 절차 제거를 우선 검토 (심평원 연계 서류 없는 청구, 모바일 청구 UX 개선 등)
- 보류 사유: 기술적 미구현 / 후단 업무(심사) 비효율화 / 추가 비용 / 민원 발생 가능성 중 하나라도 해당하면 보류
- 정식 적용: 시스템 안정화·오류율 + 고객·직원 피드백 모두 확인

## 데이터
- 민원·CS 통계, 청구 로그, 처리기일 지표: RAG + python 집계
