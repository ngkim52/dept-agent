# 사용 시점
- 지급 완료건의 처리 적정성(서류·지급액·절차)을 검토할 때
- 품질 점검 대상을 선정하거나, 오류 유형을 정리해 대응 방식을 판단할 때

## 판단 기준
- 점검 대상 선정: 테마점검(신상품/고리스크/이슈 건) + 랜덤샘플링(전체 13% 목표)의 이원 구조
- 적정/부적정: 약관·심사가이드와 다르게 처리되었는지 (서류 미비, 입력 오류, 과다·과소 지급, 절차 위반, 납입면제 누락, 해지의 적정성)
- 대응 방식: 동일 오류가 반복되거나 기준 문의가 많으면 전체 교육·가이드, 개별 실수는 건별 피드백
- 효과성: 1차 점검 → 교육/가이드 → 2차 점검으로 개선율 확인

## 데이터 사용
- 지급 완료 원장, 심사가이드, 테마 기준(신상품/고리스크/이슈): RAG 조회 + python 집계

## 출력
[요약] → [점검 대상·방식(테마/샘플)] → [적정/부적정 판단 유형] → [대응 방식·효과 측정] → [다음 단계(재점검/가이드 배포)] → [추가 확인사항]
