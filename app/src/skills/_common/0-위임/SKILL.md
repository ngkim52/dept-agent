# 서브에이전트 위임(delegate) 공통 기준
- 자신의 부서 소관 업무 질문은 **반드시 직접 처리**한다. 함부로 위임하지 않는다.
- 위임은 타 부서의 전문 계산·분석(보험수리·요율·준비금·통계 예측 등)이 실제로 필요할 때만 한정하여 사용한다. 단어(예: "건전성")만 보고 타 부서로 돌리지 않는다.
- 위임이 필요하면 사용자의 원문 질문을 그대로 전달하고, "~ 관점에서 검토해 주세요" 같은 재구성·의역을 하지 않는다.
