## F2/F3. 프롬프트 모듈화 + 전체 재구성

- **해법**:
  - `lib/agent/promptModules.ts` — 페르소나 프롬프트를 명명된 모듈로 분해: `role`(기본/역할), `process`(판단 6STEP), `websearch`, `style`(유형별 표준), `domains`(업무영역 안내), `baseProcess`, `dataQuestion`, `intent`(의도 A/B/C), `delegate`.
  - `skills.ts` — `selectSkillsForQuestion(personaKey, question, categoryKey)` 추가: 질문/카테고리 → 해당 업무 스킬만 선택(미매칭/기본 질문=0-기본처리). `buildPersonaSystemPromptWithHarness` 옵션에 `question`/`selectedSkills` 지원, 기본(미지정)=전체(하위호환).

## F4. 녹음 기능 + 회의록 → 지식 적재
- **프로세스**: 녹음(MediaRecorder, 웹) → 오디오 저장 → 텍스트 전사(플러그형, STT 미설정 시 수동 입력/더미) → 회의록 생성(LLM: 참석/안건/결정/액션) → 편집 → **지식(메모리)로 적재** → 대화에서 활용.
- **DB**: `meetings` 테이블(대상 부서, 원문 텍스트, 회의록 JSON, 상태, 지식 반영 여부). 마이그레이션 0008.
- **API**: 
  - `POST /api/meetings/transcribe` (오디오 업로드 → 전사 텍스트)
  - `POST /api/meetings/draft` (원문 → 회의록 초안 LLM)
  - `POST /api/meetings` (저장)
  - `POST /api/meetings/:id/knowledge` (회의록 → 지식 메모리 적재 + edge 연결)
- **UI**: `meetings/page.tsx` — 녹음 버튼(시작/일시정지/정지/미리듣기) + 전사 편집 + 회의록 초안 미리보기/편집 + "지식으로 저장".
- **파일**: 마이그레이션, `lib/meetings.ts`, `api/meetings/**`, `meetings/page.tsx`, `nav.ts`(링크).
